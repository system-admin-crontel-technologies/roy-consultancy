# Android staff app (planned)

Kotlin + Jetpack Compose companion app for staff. Not yet scaffolded; it will be generated once the
Super Admin web phase is accepted so that it targets a settled API.

Planned phase 1 scope: sign in (`POST /auth/login` with `client: "MOBILE"`, Bearer tokens with refresh
rotation), Super Admin overview, user list and status actions.

Tooling present on the development machine: JDK 21, Android SDK at `~/Android/Sdk`.
